# 編集可能な地形

地形は地図画像ではなく、保存と共同編集に含まれる高さ関数として扱います。`UrbanTerrain` が計算を担当し、`EditableTerrainRenderer` が同じ高さ関数を描画します。専用サーバーは画像、メッシュ、GPUを必要としません。

## 操作と単位

| 操作 | 動作 |
| --- | --- |
| 盛土 | ブラシ中心を指定量だけ上げ、円の外縁へ滑らかに減衰します。 |
| 掘削 | 同じ減衰で高さを下げます。海面より低くなると水域になります。 |
| 整地 | 円内を目標標高へ近づけます。中心は目標高に一致します。 |
| 平滑化 | 実行直前の円内29標本の平均高へ近づけます。1回の変化量は指定量以内です。 |
| 水面高 | 都市全体の海面を変更します。地形そのものは移動しません。 |

座標 `X` と `Z`、計算結果 `Y` はゲーム単位で、1単位は10mです。ブラシの半径・変化量・保存する目標標高の単位はmです。保存する標高は原点ENU Upからの高さなので、画面で海面からの高さを入力するときは海面高を加算します。

ブラシは保存順に適用します。例えば盛土の後の整地は盛土を含めた地表を整地します。平滑化の平均高も実行直前の編集結果から求めるため、保存読込・取消・やり直しで同じ結果を再構築できます。標高格子へ丸めて保存しないので、元DEMの格子より小さい1m半径の編集も保持します。

## 初期の海底と陸域

原典DEMの水域は測深した海底ではありません。そのまま地表として使うと水面上に陸地があるように判定されるため、ゲーム用の初期地形では国土地理院の陸水ポリゴンを組み合わせます。

- 原典の水域から576点の候補標高を取り、中央値を初期海面高とします。
- 原典の水域は初期海面から少なくとも3m下の海底として扱います。
- 原典の陸地は元の標高を保ち、初期海面から0.4m以下の部分を0.4mへ補正します。
- 地形編集後は現在の地表高と海面高を比較し、埋立・掘削・水面変更の結果を陸水判定へ反映します。

この海底と最低陸地高はゲームのための補正で、現地の測深値や堤防高さを再現するものではありません。元の標高ファイルは変更しません。

## 描画と性能

通常表示は地表色と水面だけを使います。元の写真に写る撤去前の建物や道路が地面に残らないためです。航空写真は利用者が明示的に有効にする参照レイヤーで、そのときだけ読み込みます。

地表を16×16のパッチへ分割し、各パッチの基本格子は33×33頂点です。ブラシの中心、半径の半分、外縁の座標を局所追加し、小さな編集の山頂や底を描画します。1軸約161標本を上限とし、最近のブラシを優先します。大量の細かい編集が同じ範囲へ集中した場合、全履歴の細部を同時に描画する解像度には限界があります。CPUの高さ関数と保存した編集内容は保持します。

更新時は変更円を含むパッチだけを予約し、通常は1フレーム最大4パッチを再生成します。法線も現在の高さから再計算します。海面変更は全パッチを更新します。建物や道路は同じ高さ関数を参照して追従します。

地物自体を上下させる操作は、地形ブラシとは別です。「高さ」またはHを選んで地物を上下へドラッグすると、地形を変えずに地物の高さ差分を変更します。「移動」Gと「回転」Rも同じ編集履歴へ確定し、左ボタンを離す前なら右クリックで取り消せます。地形への追従を解除した地物は絶対高さを使います。

住民・車・電車は現在の地表高と経路に沿って表示し、船は現在の海面高を参照します。ただし造成による勾配制限、浸水による通行止め、橋やトンネルの構造判定はまだ交通計算へ実装していません。地形編集だけでその場所の交通網を自動修復・再設計する処理もありません。

地形ブラシのCPU評価には200m四方の空間索引を使用します。無関係な場所の履歴は走査しません。最大25万の座標標本には適用済み履歴長と高さを記録し、同じ頂点の次の更新は追加したストロークだけを計算します。取消や読込で過去のブラシが変わった場合は標本を破棄し、順序を保って再構築します。海岸線や穴を含まない索引セルは陸水を事前に確定します。

造成時の照準はCPUの高さ関数へ視線を歩進し、最初の交差区間を二分探索して求めます。ブラシ付近では半径に応じて歩幅を細かくし、円への進入・最近接・退出も必ず標本化します。急斜面で収束しない固定点反復は使いません。元DEMより細かい編集も照準に反映します。

## 検証

`EditableTerrainTests.Run` は実データを使用し、盛土・円外不変・平滑化・保存復元・取消・1m半径・整地の順序・埋立・水没・海面復元をGPUなしで検証します。半径1mで200m盛土した急斜面を視線が捉え、交点が地形と視線の両方に一致することも検証します。成功時に `BAYFRONT_TERRAIN_PASS` とCPU標高照会の実測時間を出力します。
