# 地物の編集と目的を持つ交通

ゲーム名は「都市づくり」です。都市名はプレイヤーがセーブデータごとに指定し、「東京ベイ」も任意の都市名として使えます。内部の地図ID `real-bayfront`、アセンブリ名 `BayfrontSandbox`、通信試験の識別子は互換性のため維持します。

## 画面と地物操作

画面下部から建物・道路・線路・航路・交差点・信号・立体物・敷地・地形・撤去を選びます。左上に選択・移動・回転・高さと選択フィルター、右側に選択対象の「設計」「形状」「運用」を配置しています。上部の「地図・検索」「人・交通」「都市・セーブ」「共同編集」で各画面を開きます。

| 操作 | 手順 |
| --- | --- |
| 選択 | 建物の屋根または壁、道路面、信号柱・灯器を左クリック |
| 移動 | 「移動」またはGを選び、地物を左ドラッグ |
| 回転 | 「回転」またはRを選び、地物を左右へ左ドラッグ |
| 上下 | 「高さ」またはHを選び、地物を上下へ左ドラッグ |
| 微調整 | ドラッグ中にShift。移動・上下0.1m、回転1度刻み |
| 確定・中止 | 左ボタンを離すと確定。右クリックまたはEscで未確定の操作を中止 |
| 輪郭変更 | 「形状・頂点」で頂点をドラッグ、または右側で座標を入力 |
| 取消・やり直し | Ctrl+Z／Ctrl+Y、または上部のボタン |

通常の水平・上下操作は1m、回転は5度刻みです。原典由来の地物も同じ操作で編集します。道路は経路全体を一緒に変換し、交差点を移動すると接続道路の対応点と所属信号も移動します。地物の上下は地形を造成する操作とは別で、地形への追従設定と高さ差分を変更します。

未変更の原典建物は描画と同じ三角形で壁・屋根を選択します。変更後の建物は現在の凹形輪郭・回転・高さから判定し、外接箱の空いた角を地物として選びません。手前の面を優先し、地形に隠れた地物も除外します。小さな人や乗り物は近景へ移動するか、選択フィルターと一覧を使います。

現在は設計を確定すると建物形状へ反映します。資材搬入や工事期間を経て完成する建設工程は未実装です。

## 最初の交通街区

1. 「都市・セーブ」から「交通の試験街区を新規作成」を選び、都市の置き換えを確認します。
2. 実地形の海岸に住宅・共同事務所・商店・駅・港・道路・線路・航路が配置されます。全て通常の地物として編集・撤去できます。
3. 時間を進めます。用途と階数を持つ住宅へ住民が段階的に入居し、指定した交通手段で目的地へ移動します。
4. 「人・交通」の一覧、または近づいて個体をクリックし、目的地と経路・状態を確認します。
5. 接続道路や現示を変更し、待機理由や移動の変化を確認できます。保存すると移動途中から再開できます。

試験街区は交通の接続を確認するための明示配置です。原典の実在施設や、編集不能な既定オブジェクトとして追加するものではありません。元の都市を残す場合は、先に別のセーブとして保存します。

## 用途と交通網

住宅の用途選択に徒歩・自動車・鉄道・船の希望手段を用意しています。用途と階数から計算する床面積を使って段階的に入居し、職場・商業・公共施設などの目的地へ割り当てます。階数0は未設定で、原典の建物高から架空の階数や人口を確定しません。画面の設計定員と実入居者数は別の値です。

| 移動手段 | 接続条件 | 不足した場合の例 |
| --- | --- | --- |
| 徒歩 | 住宅と目的地へつながる歩道付き道路 | 歩道が接続していない |
| 自動車 | 車線のある道路と、通行方向に沿った経路 | 一方通行で到達できない |
| 鉄道 | 2か所以上の駅、駅を結ぶ線路、両端の徒歩接続 | 駅がない、線路が切れている |
| 船 | 2か所以上の港、港を結ぶ航路、両端の徒歩接続 | 港がない、航路や徒歩接続が切れている |

道路・線路・航路は編集可能な線形です。公的な道路中心線を取り込んだだけで駅・線路・港・航路が自動整備されるわけではありません。建物と交通網への接続は近接位置から求める現在の試作で、個々の出入口やホーム位置を指定するデータモデルは未実装です。

住民は固定の住居と勤務先、買物・余暇の訪問先、現在の滞在先、希望交通手段、次の行動と時刻を別に持ちます。移動中の滞在先は空で、到着後に施設を記録します。店舗は勤務先と買物先の双方、公園の敷地は余暇の訪問先として使えます。訪問先を固定職場に上書きする処理にはしません。

移動個体は目的・出発地・目的地・経路・経路内の位置・待機理由を持ち、通勤・買物・余暇・帰宅を行います。接続がなければ無関係な場所を歩かせず、理由付きで待機します。道路などの編集時は実在する経路を再探索し、撤去した線上を走り続けません。

信号制御した交差点では現示と許可道路を使って進入可否を計算し、自動車には先行車待ちを反映します。原典から推定した未設定信号へ、実在の交通規制として青時間を割り当てる処理はありません。

## 個体の情報と追跡

人・車・電車・船を選ぶと、右側へ種類・名称・状態・今回の目的・出発地・行先・交通手段・残り経路・乗員または乗客数・待機理由を表示します。住民は住居・固定職場・現在の滞在先も区別して表示します。実在する住居・職場・行先へのリンクと、車両から乗員・乗客を選択するリンクを用意しています。

「今回の経路を表示」で経路を切り替え、「追跡 オン／オフ」または「追う」で追跡を切り替えます。手動パンや地区移動でも追跡を解除します。屋外の個体は補間した三次元表示位置を追い、建物内・乗車中の個体では建物または乗車先へ視点を合わせます。停止中でも追跡表示と実際の追跡状態を揃えます。「人・交通」の一覧は停止中の初回表示でも最新状態からすぐ作成し、同じ個体のボタンは保持して状態の文字だけを更新します。

在宅・就業・施設内滞在の住民と、乗車中の人は屋外へ重複描画しません。住民の実在状態は都市データに残ります。建物を選択すると実入居者数と勤務先に設定された人数を確認できます。車両の乗客は住民の識別子へ結び付け、飾りの車列を別に発生させる方式にはしていません。

クライアントはCPUで確定した位置の間だけを補間します。時間を停止すると表示の移動も止まり、描画側だけで目的地を作って移動を継続することはありません。

## 保存と共同編集

「都市・セーブ」で都市名を変更し、「別のセーブとして保存」で独立した都市保存を作ります。通常の保存は現在の保存を更新し、未保存都市では新しい内部識別子を作ります。都市名は制御文字を含まない1～80文字で、都市名をパスやファイル名として使いません。

| 状態 | 保存内容 |
| --- | --- |
| 都市 | 都市名、地図ID・版、資金、日付、速度 |
| 設計 | 原典を含める設定、地物の変更・新設・削除、地形・水面 |
| 時間 | 整数秒と端数秒 |
| 住民と交通 | 住居・固定職場・訪問先・滞在先・次の行動・希望手段・個体・経路・移動途中の位置と待機理由 |

保存先は `user://cities/saves/<保存識別子>.json` で、Windowsの標準では `%APPDATA%/Godot/app_userdata/都市づくり/cities/saves/` です。上書き前の内容を `.bak` へ残します。旧単一保存と旧アプリ名の保存も一覧から読み込み、都市名項目のない旧保存には「名前未設定の都市」を表示します。

都市の正本を持つホストだけが保存・改名・都市の置き換え・速度変更を行います。参加者は共有都市を保存・再ホストせず、切断後は参加前の都市へ戻ります。時計と交通の更新は編集版を増やさず、設計とは別の稼働通知で同期します。取消・やり直しでは都市時計を巻き戻しません。

## 現段階の上限と未実装

- 個別計算は最大512人、住民と乗り物の状態は合計最大1,024件です。原典都市全人口の再現ではありません。
- 鉄道・船は目的旅客に対応する乗り物を生成する最小実装です。複数の旅客が共有する便、運行ダイヤ、運行頻度・運賃・乗換計画は未実装です。
- 車線変更、駐車、詳細な交差点内の走行曲線、衝突回避、実交通量による需要推計は未実装です。信号待ち・先行車待ちを完全な交通シミュレーターと同一視しません。
- 車両の実乗員・乗客へのリンクはありますが、車両の所有者、運転者、同乗者を役割別に分けるモデルは未実装です。施設本体と付属施設を任意の一群として選択し、一括移設・回転する機能も未実装です。
- 貨物・生産・経済・電気・上下水道・災害・区画の自動成長・工事工程は未実装です。通勤到着を収益へ結び付ける計算も未実装です。
- 造成に伴う勾配・浸水・橋梁・トンネルの通行可否を厳密に評価する処理は未実装です。

`test.ps1` は変換の深い複製と逆変換、回転した壁・凹形・屋根・地形遮蔽・道路・信号灯の選択、個体表示と側面選択、複数保存と都市名、不正な保存経路の拒否を検証します。目的交通は四手段の実移動、分断、一方通行、赤信号、保存再開をCPUで検査し、実ENetの2プロセスでは都市名・個体・経路・時計と所有権を確認します。

`Tests/TrafficCity.tscn` は実地形へ交通試験街区を配置し、住宅の重複がないこと、都市として保存検証を通ること、600秒の計算で四交通手段と目的地到着が発生することを検査します。

Cities: Skylines IIの実行中都市では、住民を選択して徒歩経路と追跡を確認し、バンの情報で所有者・運転者・乗客を確認しました。鉄道路線一覧→路線→列車個体の順で追跡し、施設本体と付属施設をまとめた移設・回転、地形の盛土・平滑化も操作しました。これは概念の確認であり、こちらのゲームが全機能を実装済みであることを示しません。
