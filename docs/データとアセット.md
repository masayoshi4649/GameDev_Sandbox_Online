# 地形とアセット

この文書は `run.ps1 -Sample` で開く旧簡略サンプルと、追加施設用の手続き型アセットの説明です。既定の実地図は [実データ構成](実データ構成.md)、[PLATEAU取込](PLATEAU取込.md)、[地表データ](地表データ.md) を参照してください。

この試作には、台場、有明、東雲、豊洲の相対的な位置と水辺の街並みを参考にした、自作の架空地形を同梱しています。実測の海岸線、行政境界、道路線形、建物配置を再現したデータではありません。移動距離、住所、防災、測量、現地案内には使用できません。

`Data/bayfront.json` の座標は東が X 正、南が Z 正です。1 単位を 10 メートル相当としたゲーム用の縮尺です。地区を隔てる運河と数本の橋を強調し、約 5 キロメートル四方に収めました。台場は南西、有明は中央、東雲は東、豊洲は北に配置しています。各地区に道路、公園、住宅、業務ビル、公共施設をあらかじめ配置します。初期建築は道路と海岸から距離を置き、同じデータから毎回同じ配置で生成されます。

東京湾岸の地区や施設の確認には、次の一次情報を参考にしました。確認日は 2026 年 10 月 16 日です。

- [東京都港湾局・臨海副都心](https://www.kouwan.metro.tokyo.lg.jp/rinkai/): 台場、有明を含む臨海副都心の地区構成。
- [東京都港湾局・豊洲・晴海開発整備計画](https://www.kouwan.metro.tokyo.lg.jp/basic/plan/toyosu_harumi): 豊洲の業務、商業、居住の複合的な土地利用。
- [東京ビッグサイト・会議棟](https://www.bigsight.jp/english/organizer/facilities/conference/): 逆ピラミッドというランドマークの形状の参考。

これらのサイトの地図、写真、図面、ロゴ、配布ファイルは同梱していません。輪郭座標、建物の寸法、配色、窓割りは本リポジトリで新規に作成しています。実在施設の公式モデルや公認表現ではありません。市販ゲームのデータ、モデル、画像、名称付きロゴも使用していません。

## 手続き型モデル

`Scripts/AssetFactory.cs` は箱、球、円柱、独自の四角錐台から低ポリの景観を生成します。素材と基本メッシュはキャッシュして共有し、外部の画像テクスチャやモデルファイルを必要としません。

| 種別 | 表現 |
| --- | --- |
| 住宅 | 淡色の外壁、青い窓、連続バルコニー、屋上設備 |
| 業務 | 青緑のガラス、垂直フレーム、階ごとの帯、入口の庇 |
| 公園 | 芝生、十字の園路、複数の樹冠色、ベンチ |
| 公共施設 | 低層の建物、緑色の庇、植栽 |
| 台場の展望施設 | 二棟を結ぶ球体展望室 |
| 有明の交流館 | 四つの逆ピラミッドと低層の基壇 |
| 豊洲の市場 | 連続した低い屋根と搬入用の庇 |
| 東雲のタワー | 高層の住宅街を象徴する段状の建築 |
| 道路・岸壁 | 縁石、車線の破線、埋立地の岸壁と水辺の遊歩道 |

地表の高さは Y=0、陸地底面は Y=-2、道路の上面は概ね Y=0.22 です。地形は描画用の簡略メッシュであり、地形編集や標高データの機能は持ちません。

## 通常の実都市と目的交通

通常起動では公的な実都市データを使用します。この文書の架空地形と独自座標は旧簡略サンプルだけのもので、緯度経度に直接対応させることはできません。実都市の取得範囲・座標・出典は [実データ構成](実データ構成.md) を参照してください。

通常画面の住民・車・電車・船は `UrbanAgentRenderer` がCPUの確定状態から描画します。目的地と経路は `UrbanSimulation` が決め、表示側で無作為に歩かせません。建物の設計、個体の選択・追跡、交通の制約は [目的交通と編集操作](目的交通と編集操作.md) に記載しています。旧簡略画面の手続き型景観と、通常画面の編集可能な実都市・目的交通は別の経路です。
